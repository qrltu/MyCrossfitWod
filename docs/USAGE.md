## 安装到手机

### iPhone / iPad（Safari）

1. 用 **Safari** 打开[在线地址](https://a9269491c75fe5d9c.app.workbuddy.host/?sharecode=SBB6EUCR4K)。
   > 必须使用 Safari，其他浏览器不支持「添加到主屏幕」的 PWA 全屏模式。
2. 点击屏幕底部中间的「共享」按钮（方框 + 向上箭头）。
3. 向下滑动，选择「**添加到主屏幕**」。
4. 名称默认为 **MyCrossfitWod**，确认后点「添加」。
5. 返回主屏幕，点新图标启动应用。

### Android（Chrome）

1. 用 Chrome 打开在线地址；
2. 右上角菜单 → 「添加到主屏幕」或「安装应用」；
3. 按提示确认。

### 桌面浏览器

直接访问在线地址即可使用全部功能，Service Worker 在 `localhost` 与 HTTPS 环境下生效。

## 界面导览

应用为单屏结构，底部固定 6 个页签，点击即切换：

```
┌─────────────────────────┐
│        内容区域          │
│                         │
├─────────────────────────┤
│ 训练计划 课表 WOD 热身 计时器 字典 │
└─────────────────────────┘
```

- 页面顶部下拉可重新加载（在线版本）；
- 标题旁的 `?` 是备注气泡：电脑上悬停显示，手机上点按显示，约 3 秒后自动消失；
- 页脚显示当前版本号（如 `版本 v2.16`），可用于确认是否已更新到最新版。

## 各页签使用

### 训练计划

应用首页，随机生成今日训练。

- **生成今日训练计划**：从内置的真实训练日、网友分享课、力量/技术模板与 WOD 中随机组合；
- **生成结果**：标题行显示时间结构（如 `EMOM 20`、`Every 4:00 × 5 组`），正文按模块分段；
- 生成后可使用两个联动按钮：
  - 「按此课表训练」→ 跳到课表页并高亮对应内容；
  - 「按此计划定时」→ 跳到计时器页，自动载入计划中的时间预设；
- 页面下方还有「我的 1RM · 配重换算」「重量与记录备忘」「训练历史」三个折叠模块。

### 课表

- 分「真实训练日 161 天」和「网友分享课 16 天」两个折叠区，默认展开，点标题展开/收起；
- 顶部搜索框可按内容筛选；
- 每条训练日卡片有编辑按钮（右下角 ✎），区标题旁有「＋ 添加」按钮；
- 编辑弹窗支持保存、还原默认值；自定义添加的条目还可删除。

### WOD

- 「WOD 索引 101 个」折叠区，支持搜索与分类筛选；
- 可同时勾选两个 WOD 进行组合训练；
- 每条卡片右下角有编辑按钮与格式一致的「＋」添加按钮（两者间隔 8px）；
- 卡片内的小闹钟可一键把该 WOD 的时间结构送入计时器。

### 热身

- 「热身拉伸 5 套」按训练类型分类：举重日 / 体操技巧日 / 有氧与 WOD 日 / 无器械通用版等；
- 每式包含时长、动作名、要领与常见错误；
- 支持编辑与新增；训练前 8–12 分钟 / 训练后 5 分钟的提示已并入标题的 `?` 备注。

### 计时器

详见[计时器详解](#计时器详解)。

### 字典

包含三个可编辑模块：

| 模块 | 数量 | 说明 |
| :--- | :--- | :--- |
| 专业术语 | 13 条 | EMOM / AMRAP / Rx / Touch & Go 等缩写与释义，默认展开 |
| 技术模板 | 65 个 | 随机生成器抽用的力量/技术课表模板 |
| 技术动作 | 176 个 | 动作中英文名、分类与要领备注 |

三个模块均支持搜索（技术动作还有分类筛选）、逐条编辑、新增与还原默认值。
> 注意：修改「技术动作」会同步影响「训练计划」页随机生成时的动作抽选。

## 计时器详解

### 基本流程

1. 选择或输入时间预设；
2. 点「开始」进入**准备**阶段（倒数 3、2、1）；
3. 自动进入**锻炼**阶段，到点切换**休息**，循环至完成；
4. 每个阶段切换会发出蜂鸣提示（Web Audio，无需音频文件）。

### 支持的预设

- `EMOM 20` — 每分钟一组，共 20 分钟；
- `AMRAP 15` — 15 分钟内尽可能多轮；
- `Every 4:00 × 5 组` — 每 4 分钟开一轮，共 5 组；
- `X′ 做功 / Y′ 休息` — 自定义间歇比例；
- `Tabata` — 20 秒 / 10 秒 × 8 组；
- 支持 `分:秒` 格式输入（如 `0:45`）。

### 项目清单高亮

在计时器中填入动作清单后，当前正在进行的动作会像「歌词」一样高亮显示，方便训练中扫一眼就知道下一步。
从训练计划或课表页跳转过来时，清单会自动带入，并停留等待你点「开始」。

### 屏幕常亮

计时器页提供屏幕常亮开关，调用 Wake Lock API 防止训练中息屏。
> 需要 iOS 18.5 及以上，且从主屏幕 PWA 启动；不支持时会有弹窗说明。

## 数据备份与恢复

### 备份哪些数据

- 各页签中所有编辑与新增的内容；
- 1RM 与重量记录；
- 训练历史；
- 自定义计时预设；
- 数据结构版本号。

### 导出

1. 打开「训练计划」页，滑到最下方；
2. 点「**导出备份**」；
3. iOS 会弹出系统文件面板，选择「存储到文件」，再挑一个你想要的文件夹（如 iCloud Drive 或「我的 iPhone」）；
4. 文件名默认含日期，建议保留。

### 导入

1. 在同一位置点「**导入备份**」；
2. 从「文件」App 选中之前导出的 JSON 文件；
3. 阅读确认提示后点「导入并刷新」；
4. 页面会自动校验并规范化数据，然后刷新生效。

> ⚠️ 导入是**全量覆盖**当前设备上的数据，操作前请确认备份文件是想要的版本。

### 兼容性

导入时会自动处理旧版本备份：缺失的模块分组自动补全、格式异常的条目自动过滤。因此即使你手上的备份来自更早的版本，通常也能直接导入。

## 更新应用

### 在线页面

Safari 中下拉刷新，或关闭标签页重新打开。看页脚版本号确认是否更新。

### 主屏幕 PWA

应用内「训练计划」页最下方有「**刷新本页面**」按钮：

1. 点击后弹出进度条：「正在清理旧缓存 → 正在准备拉取最新版本 → 即将刷新」；
2. 完成后页面自动重载，此时已是最新版；
3. 若某次更新涉及数据结构变化，会先弹窗提示你导出备份。

如果在 Safari 中刷新后仍是旧版本，可关掉标签页重开一次；Service Worker 的更新常需第二次导航才生效。

> 图标更新例外：iOS 会缓存主屏幕图标，需要删除旧图标再重新「添加到主屏幕」。

## 常见问题

**Q：添加到主屏幕后打开是空白或错误页？**
A：旧版图标的启动地址可能已失效。删除图标，在 Safari 重新打开在线地址（确认能看到完整页面），再重新添加到主屏幕。

**Q：数据会同步到 iCloud 吗？**
A：不会。PWA 没有 iCloud 同步接口，数据只存在当前设备的浏览器存储中。换机请用导出/导入迁移。

**Q：清了网站数据，记录没了怎么办？**
A：无法恢复，除非之前导出过备份。这也是建议定期备份的原因。

**Q：为什么计时器没有声音？**
A：iPhone 需取消静音模式；首次交互后 Web Audio 才被允许发声，所以要先点一次页面再开始计时。

**Q：编辑内置条目后，更新版本会不会丢失？**
A：一般不会。编辑按条目键或标题定位保存；但如果后续版本改了内置条目的标题，旧修改可能不再匹配——这种结构变化会提前弹窗提醒备份。

**Q：屏幕常亮开关灰色不可用？**
A：需要 iOS 18.5+ 且从主屏幕 PWA 启动。用 Safari 直接打开网页时系统不提供该能力。
